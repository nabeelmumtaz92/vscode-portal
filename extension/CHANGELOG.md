# Changelog

## 0.2.0

- **Screen tab:** see the Mac's whole screen and control it from your phone. Touch and Trackpad modes, pinch zoom, right-click and click-drag, an iPhone keyboard with a row of special keys, clipboard sync both ways, and Claude in a sheet over the live screen. Hardware H.264 at up to 30 fps, with flow control that lowers quality on a weak connection instead of falling behind. Works on the same Wi-Fi, over Tailscale and through the end-to-end encrypted relay. Off until you run "VSCode Portal: Turn On Screen Sharing".
- Connect from anywhere through an end-to-end encrypted relay, or directly on the same Wi-Fi, by scanning a QR code.

## 0.1.0

First release.

- Claude Code prompts from your phone in Auto-edit, Plan only and Full access modes, with streamed replies, tool cards, diffs and cost.
- Live editor that syncs both ways with the VS Code window on your Mac, plus Follow mode.
- File browser and search.
- Changes: git status, diffs, commit, push, Problems, and "Ask Claude to fix".
- Terminal: run commands with output on your phone, or send them to the VS Code terminal on your Mac.
- One server per VS Code window, protected by an access code.
